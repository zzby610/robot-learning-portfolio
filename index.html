02 / World action models

Video and action prediction for dual-arm manipulation

LingBot-VA predicts how the scene will change alongside the actions the robot should take. I adapted its post-training and action interface for the AcOne dual-arm robot, from preprocessing demonstrations to running the trained policy in a closed loop.

03 / Real-time control

Continuous execution with real-time chunking

I adapted LingBot-VLA training and inference for real-time chunking (RTC). The controller prepares the next action sequence while the robot executes the current one, reducing the pause between chunks.

Measured on hardware: the wait between action chunks fell from about 137 ms to 0 ms, with task success unchanged. This measures the pause at handoff; the model still takes time to compute the next chunk.

Lund University

Robotics Lab · Student Research Project

Feb – May 2025

From action tokens to UR5e deployment

  • Conducted a sim-to-real study adapting OpenVLA-style action-token policies from LIBERO simulation data to a UR5e real-robot manipulation setup.
  • Implemented a 256-bin action-tokenization pipeline mapping continuous 7D end-effector commands into discrete tokens, followed by LoRA fine-tuning with LIBERO data and 183 real-robot trajectories.
  • Used Set-of-Mark-style visual target annotations and trajectory-based motion cues to organize action-grounded supervision for downstream adaptation.
  • Deployed the policy through ROS 2 with asynchronous inference, achieving 61% success on real-world pick-and-place trials and analyzing discretization errors, inference latency, visual shift, and rollout instability.
