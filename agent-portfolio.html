01 / ERICSSONMaster’s thesis · Jan – Jun 2026

SP Copilot: an agent workflow
for enterprise information and actions

A router–executor agent combining retrieval grounding, tool orchestration, evidence filtering and human review for summaries, risk analysis and data synchronization.

  • Agent orchestration
  • MCP
  • Confluence & Jira
  • Streamlit
  • Human-in-the-loop

The workflow

Users work through a Streamlit interface to request summaries, review risks, prioritize Jira items and prepare updates. The architecture separates the routing decision from the skills that carry out each task.

Engineering focus

  • Tool integration. An integration facade connects MCP servers for Confluence, Jira and FPT, with a native API fallback.
  • Context preparation. Tiered fetching and cleaning, explicit overrides and XML context fusion produce a context snapshot for the executors.
  • State across interactions. Conversation state and an asynchronous summary job support context reuse by the router and skills.
  • Review before action. Read-only skills handle wiki queries, summaries, risk and priority analysis; synchronization follows an explicit human approval step.

Designed for a user-facing workflow

The interface exposes connected sources, optional FPT context and context inspection tools, alongside the assistant’s task controls.
